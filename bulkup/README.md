# 아더댄웍스 · 내 그림의 다음 프로젝트

아이패드에 그려 둔 그림 한 장을 그림책 장면, 메모지, 이모티콘, 인스타툰, 포트폴리오 중 어디로 가져갈지 정하는 서비스다. 17년 차 디자이너 소랭이 수업에서 해 온 판단을 개별 피드백으로 구매할 수 있게 했다. 초기 사업 가설과 출시 판단은 [운영 설계도](bulkup-blueprint.html)에 있다.

## 고객과 대표의 사용 순서

1. 고객이 푸른 폴더 캐릭터 아래에서 무료 진단을 시작하고 21문항에 답한다. 로그인과 연락처 없이 결과가 열린다.
2. 8유형은 선·형태·정서로 정한다. 전체 6축은 응답의 위치로 보여 준다. 무료 결과는 희망 분야에 맞춰 제안할 대상, 제안 문장, 확인할 반응을 담은 판매 실험 하나를 보여 준다. 진단 점수와 순위는 희망 분야를 바꿔도 같다.
3. 무료 결과 아래에 피드백 항목과 블라인드 미리보기가 열린다. 피드백 1회 런칭가는 19,000원이다. 자료는 최근 그림 1~3장과 목표 한 가지다. 인스타 DM에서 접수·결제 방법을 안내한다. 기존 결제 페이지가 있으면 공용 설정의 report 링크로 연결한다. 결제와 자료 접수 후 2영업일이 전달 기준이다.
4. 대표는 six-axis-studio.html에서 제출작을 확인하고 ‘살릴 디테일’, ‘바꿔 볼 선택’, ‘다음 프로젝트와 확인 방법’을 작성한다. 고객용 미리보기에서 HTML 저장 또는 텍스트 복사를 선택한다. 심화 분석은 별도 화면에서 열 수 있다. AI 분석과 기록 저장은 지원되는 Claude 런타임에서 사용한다.
5. 수업 신청은 별도의 선택지다. 작품 사례 공개와 수업 홍보 연락은 각각 용도를 설명하고 동의를 받은 경우만 진행한다.

## 운영 설정

공개 화면은 free-diagnosis.html, 공용 규칙·가격·수업·링크는 otw-core.js, 구글 시트 수집기는 lead-collector.gs다. 공개용으로 빌드할 때 다음을 실행한다.

    node bulkup/tools/build-public.cjs

public 폴더의 index.html, JS, assets를 함께 배포한다. 대표용 스튜디오와 운영 설계도는 운영자 자료로 관리한다. 기존에 따로 게시한 Claude 아티팩트에는 저장소 변경이 자동 반영되지 않는다.

무료 결과는 설정 없이 작동한다. 이메일 사본과 질문 수집을 열 때에는 운영자 소유 시트에 Apps Script를 웹앱으로 배포한 뒤 CONFIG.leadEndpoint를 설정한다. 선택한 고객의 동의 입력만 전송한다. 서버 영수증에서 저장 여부와 메일 처리 결과를 따로 표시한다. 결과메일 재발송 필요 상태는 운영자가 시트에서 확인한다. 중복 접수는 leadId로 식별한다. 이전 JSON 방식 요청도 받는다. 결제 링크를 설정하기 전에는 DM 신청으로 운영한다.

## 첫 판매 검증

첫 5건에서 유입 경로, 주문·결제·자료 제출·발송, 실제 결제액, 전체 작업 시간, 7일 뒤 실행 여부를 기록한다. 문의 중 결제한 비율과 자료 제출 후 납기 준수율을 나눠 본다. 시간당 비용은 대표가 정한다. 19,000원에 30분을 쓰면 수수료와 도구비 차감 전 시간당 매출은 38,000원이다. 이 기준에서 수익이 남는지 확인한 뒤 범위와 가격을 조정한다. 신규 문의와 기존 수강생은 분리한다. 가상 패널의 반대 이유는 인터뷰 질문으로 사용한다.

## 확인 명령

    node bulkup/tests/personas.cjs
    node bulkup/tests/free-e2e.cjs
    node bulkup/tests/studio-e2e.cjs

브라우저 테스트는 Playwright와 Chromium이 필요하다. 시스템 브라우저를 쓰는 경우 CHROMIUM_PATH로 지정한다. 테스트의 메일과 Claude 호출은 모의 환경을 사용한다.
