# MVP 검증: 가상 이사회 + 가상 구매자 패널

오픈소스 [founder-skill](https://github.com/Jakeschincariol/founder-skill)(MIT)의 `founder-board`·`founder-consumer`·`founder-pricing` 절차를 그대로 따랐어요. 구매자 도구는 한국 이름, 연 소득 만 원 단위, 한국어 질문지로 바꿔 `tools/panel_ko.py`에 두었어요. 계산 로직은 원본과 같아요.

> 가상 구매자는 진짜 고객이 아니에요. 반대 이유와 문구를 찾는 데는 좋지만 구매율 예측에는 약해요. 큰 결정은 실제 사람(사전 예약, 대기 명단, 가격이 적힌 랜딩)으로 확인하세요.

## 결과 한눈에

| 항목 | 결과 |
|---|---|
| 이사회 (오퍼·독점·제품 관점) | **FUND IF 3표**, 평균 4.7/10 → `board.md` |
| 원래 안: 무료 진단 → 리포트 29,000원(런칭가 19,000원), 100명 | 무료 진단 시도 **100명** · 유료 구매 **0명** · 수업 관심 '낮음' 7명 |
| 개선안: 샘플 공개·12,900원·그림 1장·환불·수업비 차감, 20명 | 무료 진단 시도 **20명** · 유료 구매 **0명** · 수업 관심 '낮음' **8명(40%)** |
| 가격 수용 범위 (원래 안 응답) | 약 5,000~24,900원. '싸다'와 '비싸다'가 같아지는 가격은 약 12,000원. 정가 29,000원은 범위 밖 |

## 안 사는 이유 (100명)

| 이유 | 명 | 대표 문장 |
|---|---:|---|
| 믿음 (AI가 내 그림을 볼까, 누가 감수하나, 수업 팔이 아닌가) | 43 | "그림 3~5장을 AI가 제대로 보는 건지 못 믿겠어요." |
| 습관 (안 읽고, 안 할 것 같다) | 34 | "14장 읽고 2주 처방대로 안 할 게 뻔해요. 안 들은 클래스가 이미 쌓여 있어요." |
| 필요 (무료로 충분) | 12 | "유형이랑 1위 길만으로도 충분할 것 같아요." |
| 가격 | 10 | "1만 9천 원이면 온라인 클래스 하나 듣는 값인데." |

마음을 바꿀 조건으로 100명 중 85명이 **'실제 샘플 리포트'**를 말했어요. 그다음은 이렇게 나왔어요.
- 후기 (25명)
- 수업 권유가 없다는 확인 (20명)
- 그림 1장으로 먼저 보기 (17명)
- 그림 보내기가 부끄러움 (16명)
- 감수자 이력 (14명)

## 개선안에서 바뀐 것

- '수업 팔이' 의심과 가격 반대가 줄었어요. 수업 관심도 0%에서 40%(낮음)로 올랐어요.
- 남은 벽은 **습관**(9/20)과 **믿음**(7/20)이에요. 샘플 '앞 3장'만으로는 부족하고, 이런 걸 원했어요.
  - 나랑 비슷한 초보의 전후 그림
  - 팔로우하는 작가의 후기
  - 그림 위에 달린 실제 코멘트
- 목표가 뚜렷한 사람은 '맞는 길 분석'이 필요 없다고 했어요. 대신 **"이모티콘 제안 통과 기준으로 봐 주기"**처럼 목표별 기준을 원했어요.

## 파일

- `idea.md`, `board/brief.md`: 이사회에 준 사업 설명
- `board/offers.md` · `monopoly.md` · `product.md`: 관점별 메모. `board.md`는 요약과 조건 체크리스트
- `customer.json`, `pitch.md`, `pitch-v2.md`: 구매자 프로필(추정값 포함)과 보여 준 제안문
- `panel/`, `panel-v2/`: 카드, 질문지, 응답, `results.md`(집계), `price.md`(가격)
- 다시 돌리기: `python3 tools/panel_ko.py --dir panel init --customer customer.json --pitch pitch.md --n 100 --seed 2026`
