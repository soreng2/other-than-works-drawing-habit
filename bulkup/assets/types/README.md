# 그림체 유형 일러스트 넣는 곳

이 폴더에 아래 8개 이름 그대로 PNG를 넣으면 무료 진단 결과 화면, 결과 카드(1080×1350), 대표용 스튜디오 결과지·카드·리포트 표지에 자동으로 들어갑니다.
파일이 없거나 깨져 있으면 기존 폴더 캐릭터가 대신 보이니 일부만 먼저 넣어도 됩니다.

| 파일 이름 | 유형 | 한 줄 |
|---|---|---|
| `clean-deform-story.png` | 표정 부자 캐릭터 작가 | 한 컷만 봐도 무슨 말을 하는지 들리는 그림 |
| `clean-deform-observe.png` | 단정한 마스코트 메이커 | 어디에 붙여도 그 자리에 어울리는 그림 |
| `clean-real-story.png` | 장면을 설계하는 연출가 | 구도부터 감정까지 계산된 한 장 |
| `clean-real-observe.png` | 정확한 기록자 | 보이는 그대로를 가장 깔끔하게 |
| `rough-deform-story.png` | 낙서로 이야기하는 이야기꾼 | 대충 그린 것 같은데 자꾸 보게 되는 그림 |
| `rough-deform-observe.png` | 생활 드로잉 수집가 | 오늘 본 것을 가볍게 모아 두는 그림 |
| `rough-real-story.png` | 손맛 짙은 그림책 화가 | 종이 냄새가 나는 장면 |
| `rough-real-observe.png` | 크로키하는 관찰자 | 빠르게, 정확하게, 살아 있게 |

## 규격

- 정사각형 투명 PNG, 800×800px 권장 (최소 520px). 화면에서는 84~260px로 줄여 씁니다.
- 캐릭터가 캔버스의 80% 안에 들어오게 여백을 두세요. 무료 결과 카드는 네이비 배경 위, 스튜디오 카드 1은 네이비 띠 위에 올라갑니다.
- 파일 하나당 500KB 이하가 좋아요. 휴대폰에서 결과가 바로 떠야 하니까요.
- 넣은 뒤 `node bulkup/tools/build-public.cjs`를 다시 실행하면 `public/assets/types/`로 복사됩니다.
- claude.ai에 올린 스튜디오에서도 보이게 하려면 게시할 때 `assets/types/*.png`를 함께 올려야 해요.
