## 0. 이 문서를 받은 AI에게

- **누구:** 아더댄웍스(other than works)는 17년 차 디자이너인 대표가 운영하는 드로잉 클래스·작가 브랜드예요. 오프라인 수업 6종, 온라인 '빈티지 온라인 드로잉 클럽', 1:1 워크숍을 운영해요. 인스타그램은 @other.than.works예요.
- **무엇을 만들었나:** 인스타 유입 → 무료 그림체 진단(21문항, 연락처 수집) → 유료 리포트(29,000원, 런칭가 19,000원, 대표 감수) → 수업으로 이어지는 퍼널이에요. 대표용 진단 스튜디오(그림 AI 분석 + 대표 감수 + 장문 리포트)도 함께 만들었어요.
- **지금 상황:** MVP는 작동하고 테스트도 통과했어요. 그런데 가상 구매자 검증에서 **유료 리포트 구매 0/100, 개선안 0/20**이 나왔어요. 무료 진단은 100% 해 보겠다고 했어요. 이사회 3관점은 모두 FUND IF(조건부)였어요.
- **함께 고민하고 싶은 질문:**

  2. 실제 샘플과 후기를 가장 빨리, 돈 안 들이고 만드는 방법은?

#### 진단 규칙

##### 제각각인 그림을 공정하게 보는 법 (이번 개편)

무료 진단을 하는 사람 대부분은 그림을 시작한 지 얼마 안 됐고, 끝까지 못 그린 그림이 많다는 전제로 짰습니다.

- **없는 건 감점이 아니라 '해당 없음'**: 풍경·정물만 그리는 사람에게 캐릭터·표정 점수를 1점 주지 않습니다. AI는 `null`, 본인 체크는 '해당 없음' 버튼. 흑백이면 색 조화, 아날로그면 디지털 활용도 빠집니다. 빠진 항목은 평균에서 제외됩니다.
- **미완성은 마감도에만**: 러프·선화·채색 중 그림도 정상 입력이고, 마감이 덜 된 건 '마감도' 한 항목에서만 깎습니다.
- **주제가 섞여 있으면**: 일관성을 '주제가 같은가'가 아니라 '손의 습관(선 굵기·색 운용·마감 방식)이 같은가'로 보고, 상품 준비도에서 일관성 비중을 절반으로 줄입니다.
- **기본기 8항목 (1~10점)**: 형태 안정감(그림체 안에서), 선 품질, 색 조화, 명암·빛, 구도·배치, 마감도, 디지털 활용, 자기 색. 길마다 무게가 다릅니다(`CRAFT_W`, 예: 그림책은 구도 30%). 상품 준비도 = 상업 신호 50% + 기본기 50%.
- **성장 단계와 등급 상한**: 기본기 평균으로 탐색기(<4.5) · 기초 다지기 · 그림체 형성기(6~) · 상업 준비(7.5~). 탐색기는 어떤 길도 C 위로, 기초 다지기는 B 위로 주지 않습니다. 답변만으로는 '상업 준비' 단계를 주지 않습니다(그림을 봐야 확인).
- **누구에게나 강점 2개**: 본인 평균보다 높은 항목에서 고르고, 점수가 낮으면 '이미 괜찮다'가 아니라 '다른 항목보다 앞서 있다'고 말합니다. 같은 항목이 강점과 약점에 동시에 나오지 않습니다.
- **디지털이 대신 해 주는 것**: 약한 항목마다 프로크리에이트 기능 팁(스트림라인, 컬러 하모니, 레퍼런스 레이어 등)을 붙입니다.

##### 점수 계산

- **AI는 관찰만** 합니다. 6축 위치·일관성·상업 신호 5가지·기본기 8항목·그림별 주제와 완성 단계, 근거 문장을 JSON으로 받습니다.
- **해석은 규칙**입니다. 종합 = 그림체 적합 45% + 상품 준비도 35% + 시장 매력 20%. 그림체 적합은 표준화해서 특정 길로 쏠리지 않게 했습니다.
- **하고 싶은 길 우선** (`GOAL_RULE`): 하고 싶은 길에 동기 가산 +6점을 공개적으로 더하고, 그래도 2위 밖이면 순위만 2위로 올립니다(★ 우선). 리포트에는 원래 점수 순위와 '1위 길에서 하고 싶은 길로 가는 다리'를 함께 씁니다. 그림체가 덜 굳은 사람도 하고 싶은 길의 수업을 추천하고, 첫 4주를 루틴 과제로 시작하게 안내합니다.
- **무료에서 새지 않게**: 무료 화면은 유형, 1위 길, 하고 싶은 길이 몇 위인지만 보여 줍니다. 잠긴 목차는 '길별 상세 분석 1·2·3'처럼 이름 없이, 잠긴 값은 페이지에 아예 넣지 않습니다. 결과를 담은 내부 상태는 `?debug=1`일 때만 꺼냅니다. (점수 계산이 브라우저에서 돌기 때문에 코드를 직접 뜯어보면 계산은 가능합니다. 완전히 막으려면 서버 계산이 필요해요.)
- **이모티콘 문턱**: 표정 폭 4, 캐릭터 고정성 4, 선 정돈 62를 못 넘으면 감점해 굿즈·그림책 쪽으로 넘깁니다 (`EMOTICON_GATE`).
- **본인 체크 + AI 합산**: 위치·신호는 AI 60%, 일관성은 50:50 (`MERGE`). 차이가 큰 축은 처방 1순위.
- **그림체 유형 8종**: 선(정돈/러프) × 형태(데포르메/사실) × 정서(서사/담백) (`TYPES`). 일러스트는 `assets/types/{key}.png`.
- **장문 리포트**: `PATH_GUIDE`, `AXIS_GUIDE`, `SIGNAL_GUIDE`, `CLASSES`를 대표의 실제 커리큘럼·말투로 바꿔 쓰면 됩니다.

#### 공개하기 (무료 진단)

[6축 — 우열이 아니라 위치] - line (선): 0 = 러프·스케치, 100 = 정돈·클린 - form (형태): 0 = 데포르메·단순화, 100 = 사실·구조 - color (색): 0 = 절제·톤온톤, 100 = 대비·고채도 - texture (질감): 0 = 플랫·디지털, 100 = 아날로그·재료감 - comp (구성): 0 = 정적·중앙, 100 = 동적·여백·대각 - mood (정서): 0 = 담백·관찰, 100 = 서사·감정 [채점 규칙] 1. position: 보이는 것만으로. 애매하면 40~60, 근거에 애매한 이유를 쓴다. 2. consistency(1~5): 그 선택이 여러 장에 걸쳐 의도적으로 유지되는 정도. 그림이 1장이면 4 이상은 매우 확실할 때만. 3. evidence: 그림 속 구체적 요소(위치·대상·도구)로 한 문장. 4. 말투: ~요/~습니다 섞은 담백한 대화체. 위로 문구·감성 문구 금지. 5. 그림이 아니면 {"error":"not_artwork"}만 답한다. 무료 진단은 '공짜로 알려 주는 것'이 아니라 연락처·고민·유입 경로를 받는 대가로 '오?'를 주는 것이에요. 유형과 1위 길은 보여 주고, 2·3위 길과 등급, 길마다의 시장·수익·로드맵은 잠가 둡니다. 결과 화면에 유료 리포트 목차가 다 보이기 때문에, 무엇이 잠겨 있는지 알아서 더 궁금해져요.
콘텐츠에서 무료 진단, 연락처, 결과 메일, 유료 리포트, 수업, 재진단 후기로 이어지고 후기가 다시 콘텐츠가 되는 순환 콘텐츠캐러셀·릴스·QR 무료 진단17문항 3분 연락처·고민결과 보기 전 게이트 '오?' 결과유형 공개·잠긴 목차 유료 리포트AI + 대표 감수 수업4주 뒤 재진단 재진단 전후 카드와 '많이 받은 질문'이 다음 주 콘텐츠가 된다 관심사 집계 시트 상위 3개 = 다음 주 캐러셀 주제

##### 콘텐츠 루프 8가지
###### 1. 유형 8종 시리즈
"8가지 그림체 유형, 당신은?" 캐러셀 한 편에 유형 하나씩. 마지막 장은 무료 진단 링크. 게시물마다 utm_campaign을 다르게 달아 어떤 유형 글이 유입을 만드는지 봅니다.
###### 2. 반전 콘텐츠
"이모티콘처럼 보이는데 사실 굿즈형인 그림" 같은 결과의 '의외였던 점'이 그대로 릴스 훅이 돼요. 실제 진단 사례는 동의받고 씁니다.
###### 3. 질문이 다음 주 주제
관심사 집계 시트 상위 3개를 매주 월요일에 확인해 캐러셀·라이브 주제로. "지난주 가장 많이 받은 질문"이라는 제목 자체가 참여를 부릅니다.
###### 4. 재진단 전후 카드
수업 4주 뒤 같은 그림 3장으로 재진단해서 축이 움직인 카드를 나란히. 후기보다 설득력이 큰 숫자 후기예요.
###### 5. 친구 공유 루프
결과 화면의 '친구도 해 보기' 링크에 ref=share가 붙어요. 시트에서 공유로 들어온 사람 수를 세면 입소문 계수가 나옵니다.
###### 6. 오프라인 QR
원흥 작업실 입구, 플리마켓 부스, 기관 수업 마지막 장에 QR (utm_source=offline). 현장에서 3분이면 끝나는 게 장점이에요.
###### 7. 기관 버전
학교·청소년센터 수업 첫 시간에 반 전체가 무료 진단 → 반의 유형 분포를 보여 주며 키트·후속 수업을 제안. B2G 제안서의 근거 자료가 됩니다.

> 가상 구매자는 진짜 고객이 아니에요. 반대 이유와 문구를 찾는 데는 좋지만 구매율 예측에는 약해요. 큰 결정은 실제 사람(사전 예약, 대기 명단, 가격이 적힌 랜딩)으로 확인하세요.

## 5-1. 이사회 요약

`bulkup/founder/board.md`

### 이사회 요약 (founder-board 방식)

**투표: FUND IF 3표 (오퍼 5 · 독점 4 · 제품 5) → 평균 4.7 / 10**

세 관점 모두 "지금 그대로는 투자 안 함, 조건을 채우면 함"이에요. 반대(PASS)는 없지만 점수는 중간 아래예요.

#### 두 명 이상이 짚은 위험 (가장 먼저 볼 것)

1. **이음매가 너무 많다 (오퍼·독점·제품 3명 모두).** 결제 링크가 없고, 인스타 DM으로 신청을 받고, 대표가 수작업으로 발행하고, 수업은 폼·노션으로 따로 가요. 사고 싶은 순간에 흐름이 끊겨요.
2. **'하고 싶은 길 2위 보장'이 진단의 정직성을 해친다 (오퍼·제품).** 이게 알려지면 진단이 아니라 판매 깔때기로 읽혀요. 공개하거나 결과 화면에 그대로 적어야 해요.
3. **대표 시간이 병목 (오퍼·독점·제품).** 리포트 1건마다 감수 시간이 들어서, 팔수록 수업 운영 시간이 줄어요. 건당 감수 시간을 아직 아무도 몰라요.
4. **14장 문서는 또 하나의 '못 끝낸 것' (오퍼·제품).** 고객이 원하는 건 정보가 아니라 결과(완성작 1장, 이모티콘 시안)예요.
5. **숫자가 없다 (독점·오퍼).** 팔로워 수, 진단 전환율, 리포트 구매율, 고객 획득 비용이 모두 비어 있어요.

#### 조건 체크리스트 (합본)

- [ ] 결과 화면에서 바로 결제하고, 자동 확인 메시지와 발행 예정일이 오게 하기 (DM 신청 없애기)
- [ ] 동기 가산을 결과 화면에 표기하거나 없애기 ("원한다고 한 길이라 +6점 했어요")
- [ ] 무료 진단의 이름과 내용 맞추기: 그림 1장이라도 받거나, '성향 진단'이라고 부르기
- [ ] 리포트 첫 장을 "핵심 진단 1개 + 2주 할 일 1개 + 맞는 수업 1개"로 요약하고 나머지는 부록으로 돌리기
- [ ] 결과 이름 걸기: "2주 안에 그림 1장 완성" 같은 결과 + 과제 제출 시 피드백 1회
- [ ] 진짜 보증 붙이기: 환불 또는 수업 등록 시 리포트비 전액 차감. 희소성은 '주당 감수 N건'처럼 실제로 있는 것만 쓰기
- [ ] 감수 10건 시간을 재서 단가가 대표 시간 가치를 넘는지 확인하기
- [ ] 첫 30건 뒤 숫자 보고하기: 진단 → 리포트, 리포트 → 수업 전환율, 받은 뒤 그림 1장을 끝냈는지
- [ ] 5개 길 중 하나를 먼저 장악하기 (예: 그림책 또는 이모티콘)

#### 의견이 갈린 곳

- **오퍼 관점**은 리포트를 수업으로 가는 다리로 보고, 스택(피드백·체험권·차감)을 두껍게 하라고 해요.
- **제품 관점**은 반대로 리포트를 줄이고 한 가지에 집중하라고 해요.
- **독점 관점**은 둘 다보다 "하나의 길에서 1등" 포지션과 데이터 해자가 먼저라고 해요.

#### 이사회가 볼 수 있는 가장 강한 버전

14장짜리 '진단 문서'를 파는 게 아니에요. **"그림 1장부터 보내면, 대표가 보고 2주 안에 끝낼 그림 하나와 할 일 3개를 정해 주고, 2주 뒤 완성작에 피드백까지 주는 1만 원대 상품"**이에요. 결과 화면에서 바로 결제하고, 마음에 안 들면 환불해요. 수업으로 가면 리포트비를 빼 줘요. 무료 진단은 정직하게 보정을 공개하고, 리드와 고민 데이터를 쌓는 입구로 써요. 이건 대표님이 처음 구상한 형태와 다른 방향이에요.

## 5-2. 이사회 메모: 오퍼 관점

`bulkup/founder/board/offers.md`

### Offers lens (오퍼 관점)
Score: 5 | Vote: FUND IF

#### 강한 점
- **도달이 쉽다.** 구매자(아이패드·프로크리에이트 입문 취미러)가 인스타그램에 모여 있고, 캐러셀 → 무료 진단 → 연락처 수집 흐름이 이미 만들어져 있다. 시장 4요소 중 "찾고 닿기 쉬움"은 확실하다.
- **노력 비용이 낮다.** 21문항 또는 그림 3~5장 업로드면 끝난다. 가치 방정식에서 '노력·희생'이 가장 작은 칸이다.
- **가능성(믿음)을 세울 재료가 있다.** 현직 작가·강사가 직접 감수하고, 오프라인 6종·온라인 클럽을 이미 운영 중이다. AI는 관찰만, 점수는 공개 규칙이라는 설계도 신뢰를 만드는 장치다.
- **사다리가 있다.** 무료 → 29,000원 → 클럽 → 55만 원 1:1 워크숍. 리포트는 단독 상품이 아니라 고가 수업으로 가는 다리로 쓸 수 있다.

#### 이걸 죽일 수 있는 것 (가장 위험한 것부터 3개)
1. **꿈의 결과가 '진단'에 멈춘다.** 고객이 원하는 건 "끝까지 완성한 그림, 이모티콘 입점, 첫 외주"인데, 팔리는 건 "내 그림체를 아는 것"이다. 14장 문서는 결과가 아니라 정보이고, 정보는 결국 가격 경쟁(런칭가 19,000원)으로 밀린다. 고통이 '거대한 고통'이 아니라 '있으면 좋은 호기심'일 위험이 크다.
2. **'하고 싶은 길 최소 2위' 규칙이 가능성을 깎는다.** 진단이 원하는 답을 보장한다는 게 알려지면 "진단"이 아니라 "판매 깔때기"로 읽힌다. 이 오퍼의 핵심 자산이 객관성인데, 그걸 스스로 훼손하는 구조다. 공개 규칙이라는 강점과도 충돌한다.
3. **결제·이행 마찰과 대표 시간 상한.** 결제 링크 없이 DM으로 신청받고, 건마다 대표가 감수한다. 구매 순간의 마찰이 크고, 29,000원짜리가 대표 시간을 잡아먹으면 본 매출인 수업 운영 시간이 줄어든다. 건당 감수 시간과 마진은 아직 아무도 모른다.

#### 창업자에게 물을 질문
- 리포트를 산 사람이 4주 뒤 "무엇을 손에 쥐고" 있나? (완성작 1점? 이모티콘 시안 몇 장?) 측정 가능한 결과로 말할 수 있는가?
- 무료 진단 → 리포트 구매율, 리포트 → 수업 전환율 목표는 얼마이며, 언제 첫 데이터를 볼 것인가? (현재 수치 없음)
- 리포트 1건 감수에 대표 시간이 실제로 얼마나 드는가? 그 시간으로 수업을 팔면 얼마를 버는가?
- 고객 획득 비용은 얼마로 가정하는가? 팔로워 기반 유기 유입만으로 첫 100건이 가능한가?
- 가격을 두 배(58,000원)로 올려도 "당연한 선택"이 되려면 무엇을 더 얹어야 하는가?
- '하고 싶은 길' 가산을 고객에게 공개할 생각이 있는가?

#### FUND IF라면: 조건
- **리포트를 결과 중심 스택으로 재구성.** 문서가 아니라 "2주 안에 그림 1장 완성" 같은 결과를 이름에 건다. 스택 예: 리포트 + 2주 처방 과제 제출 시 대표 피드백 1회 + 클럽 첫 회 체험권 + 리포트 금액 수업 전액 차감.
- **진짜 보증을 붙인다.** 예: "2주 처방을 따라 했는데 방향이 안 잡히면 환불" 또는 "수업 등록 시 리포트비 전액 차감". 가짜 마감·가짜 한정은 쓰지 않고, 대표 감수 가능 건수(주당 N건)라는 실제 희소성만 쓴다.
- **동기 가산을 투명하게.** "하고 싶은 길 보정"을 결과 화면에 명시하거나 순수 점수와 나란히 보여 준다.
- **결제 링크와 자동 발송을 먼저 구축**하고, 건당 감수 시간을 10건 측정해 단가가 대표 시간 가치를 넘는지 확인한다.
- **첫 30건 후 숫자 보고:** 진단→리포트, 리포트→수업 전환율. 리포트→수업 전환이 확인되면 리포트 가격보다 수업 쪽 스택 강화에 투자한다.

## 5-3. 이사회 메모: 독점 관점

`bulkup/founder/board/monopoly.md`

### Monopoly lens (독점 관점)
Score: 4 | Vote: FUND IF

#### 강한 점
- **작은 시장에서 시작한다.** "한국의 아이패드·프로크리에이트 입문~초중급 취미러 중, 완성 못 한 그림이 많고 자기 강점을 모르는 사람"은 독점 관점이 원하는 좁고 정의된 출발 시장이다. 넓은 '그림 강의' 시장이 아니라 '내 그림체가 어느 길에 맞는가'라는 질문 하나를 선점하려는 시도다.
- **진단이 유통 장치를 겸한다.** 무료 진단이 연락처와 고민을 받아 리드를 쌓고, 결과(1위 길·하고 싶은 길)가 곧바로 수업으로 연결되도록 설계돼 있다. 제품 안에 유통 경로가 들어 있다는 점은 이 관점에서 드문 장점이다.
- **복제하기 어려운 재료가 일부 있다.** 오프라인 클래스 6종과 온라인 클럽을 이미 운영하는 대표가 직접 감수한다는 점, 그리고 진단이 쌓일수록 생기는 "어떤 그림체가 어떤 길에서 막히는가"에 대한 데이터는 경쟁자가 바로 가질 수 없다.
- **공개된 점수 규칙 + AI는 관찰만**이라는 구조는 신뢰를 브랜드 자산으로 쌓을 수 있는 토대다.

#### 이걸 죽일 수 있는 것 (가장 위험한 것부터 3개)
1. **10배 우위가 없다.** 6축·기본기 8항목·8유형 프레임은 문서로 공개되는 순간 복제된다. 그림을 올리면 범용 AI가 즉석에서 피드백해 주는 시대에, 29,000원 리포트가 무료 대안보다 무엇이 10배 나은지가 아직 증명되지 않았다. 6개월 차 카피캣(다른 프로크리에이트 강사, 강의 플랫폼의 '무료 레벨 테스트')을 막을 장치가 지금은 브랜드 하나뿐이다.
2. **유통이 단일 채널이고 숫자가 없다.** 인스타그램 캐러셀 → 진단 → DM 신청이라는 한 줄짜리 경로에 모든 것이 걸려 있다. 팔로워 수, 진단 전환율, 리포트 구매율, 고객 획득 비용이 모두 미정이라, 첫 100명이 어디서 얼마에 오는지 답할 수 없다. 결제 링크도 자동 발송도 없어 퍼널 중간이 끊겨 있다.
3. **규모의 경제가 반대로 작동한다.** 리포트 1건마다 대표의 감수 시간이 들고, 수업도 대표 1인이 운영한다. 고객이 늘수록 단위 비용이 줄지 않고 대표 시간이 병목이 된다. 독점 관점에서 이는 확장할수록 약해지는 구조다.

#### 창업자에게 물을 질문
- 같은 인스타 사용자에게 지금 닿아 있는 경쟁 대안(다른 강사, 강의 플랫폼, 범용 AI 피드백)은 무엇이고, 각각 대비 이 리포트가 확실히 나은 한 가지는 무엇인가?
- 대표가 수업 현장에서 알게 된, 다른 강사들은 모르는 "비밀"은 무엇인가? (예: 입문자가 마무리를 못 하는 진짜 이유) 그것이 진단 규칙에 실제로 들어가 있는가?
- 첫 100명의 리포트 구매자는 어디서 오며, 1명당 비용은 얼마로 예상하는가? (현재 미지수)
- 진단 데이터가 쌓이면 무엇이 더 좋아지는가? 1,000번째 사용자가 10번째 사용자보다 더 정확한 결과를 받게 되는가?
- 감수 시간을 줄이면서 품질을 유지할 계획은 무엇인가? 대표 없이도 리포트가 '아더댄웍스'다울 수 있는가?
- 5개 길 중 가장 먼저 "이 분야는 여기"라는 인식을 독점할 하나의 길은 무엇인가?

#### FUND IF라면: 조건
- **하나의 작은 시장을 먼저 장악할 것.** 5개 길을 동시에 밀지 말고, 하나(예: 이모티콘 또는 그림책)를 골라 "그 길을 준비하는 프로크리에이트 입문자라면 여기서 진단받는다"는 위치를 만든다.
- **유통 숫자를 확보할 것.** 결제 링크를 붙이고, 진단 시작 → 연락처 → 리포트 구매 → 수업 전환율과 1인당 획득 비용을 측정해 다음 검토 때 제시한다.
- **데이터를 해자로 만드는 설계를 보여줄 것.** 누적 진단·리포트·수업 결과를 연결해, 시간이 갈수록 진단이 정확해지고 경쟁자가 따라올 수 없는 근거가 된다는 계획을 제시한다.
- **대표 시간 의존을 줄이는 경로를 제시할 것.** 감수 1건당 소요 시간을 재고, 그것이 줄어드는 구조(템플릿화, 감수 범위 축소 등)를 보여준다.

## 5-4. 이사회 메모: 제품 관점

`bulkup/founder/board/product.md`

### Product lens (제품 관점)
Score: 5 | Vote: FUND IF

#### 강한 점
- **중심에 진짜 사람이 있다.** 현직 작가·강사인 대표가 직접 감수하고, 이미 오프라인 6종 수업과 온라인 클럽을 운영 중이다. 리포트가 수업으로 이어지는 길이 이론이 아니라 실제로 있다.
- **디테일에 대한 원칙이 보인다.** AI는 '관찰'만 하고 점수는 공개 규칙으로 매긴다. 캐릭터가 없는 그림은 감점하지 않고 '해당 없음'으로 처리한다. 고객이 들여다보지 않는 곳까지 신경 쓴 흔적이고, Product lens가 가장 높게 치는 부분이다.
- **무료 결과에 바로 할 일이 있다.** 7일 루틴과 숨은 강점 2개는 "끝까지 못 그리는" 입문자에게 오늘 할 일을 준다.
- **MVP는 이미 만들어져 있다.** 진단 페이지, 대표용 스튜디오, 수집기가 있다.

#### 이걸 죽일 수 있는 것 (가장 위험한 것부터 3개)
1. **가장 중요한 순간에 경험이 끊긴다.** 결과를 보고 "더 알고 싶다"는 마음이 가장 큰 순간에, 결제 링크 없이 인스타 DM으로 신청하고 대표가 직접 감수해 발행한다. 그다음 수업은 구글 폼과 노션으로 따로 간다. 인스타, 정적 페이지, 구글 시트, DM, 수작업 발행, 폼, 노션까지 이음매가 일곱 군데다. Product lens로 보면 이 이음매 하나하나가 곧 제품이고, 지금은 그 대부분을 고객이 혼자 건너야 한다.
2. **진단의 정직성이 제품의 전부인데, 그게 흔들릴 수 있다.** 이름은 '그림체 진단'인데 무료 진단에서는 그림을 한 장도 보지 않는다(21문항만 받는다). 여기에 '하고 싶은 길'은 동기 가산으로 무조건 2위 안에 들게 되어 있고, 그 목적은 수업 연결이라고 명시돼 있다. 고객이 이걸 눈치채는 순간 리포트 전체가 판매 장치로 읽힌다. 보이지 않는 곳에서 깎은 모서리는 결국 보이는 곳에서도 드러난다.
3. **초점이 없다.** 6축, 기본기 8항목, 유형 8종, 단계, 5개 길, 시장분석, 2주·4주·12주 계획, 14장 분량, 수업 세 갈래. 그림을 끝까지 못 그리는 사람에게 14장짜리 문서는 또 하나의 '끝내지 못한 것'이 될 위험이 크다. 게다가 건마다 대표 시간이 들어서, 문서가 두꺼울수록 품질이 먼저 무너진다.

#### 창업자에게 물을 질문
- 이 서비스를 한 문장으로 말하면 무엇인가? 무료 진단, 리포트, 수업 중 반드시 탁월해야 하는 '하나'는 무엇인가?
- 인스타 캐러셀을 본 사람의 첫 5분을 화면 단위로 설명해 달라. 연락처를 입력하는 순간 이탈하는 사람은 얼마나 되나? (열린 질문: 아직 숫자가 없다.)
- DM으로 신청한 뒤 리포트를 받기까지 실제로 며칠이 걸리나? 그동안 고객은 무엇을 받나?
- 리포트를 다 읽은 고객이 다음 날 하는 행동은 정확히 무엇인가? 14장 중에 실제로 행동을 바꾸는 페이지는 몇 장인가?
- 5개 길 각각에 맞는 수업이 지금 다 있나? 없는 길이 1위로 나오면 고객은 어디로 가나?
- 동기 가산을 고객에게 공개할 수 있나? 공개하지 못한다면 그 이유는 무엇인가?
- 14장에서 절반을 잘라야 한다면 무엇을 자르겠나?

#### FUND IF라면: 조건
1. **결제와 발행이 한 흐름으로 이어질 것.** 결과 화면에서 바로 결제하고, 자동 확인 메시지와 예상 발행일을 받는 구조를 만든다. DM 신청은 없앤다.
2. **진단을 정직하게 만들 것.** 동기 가산을 결과 화면에 그대로 밝히거나("당신이 원한다고 한 길이라 가산했습니다") 없앤다. 무료 진단은 '그림체 진단'이 아니라 '성향 진단'이라고 부르든, 그림 1장이라도 받든, 이름과 실제 내용을 맞춘다.
3. **리포트를 줄일 것.** 핵심 진단 하나, 다음 2주 동안 할 일 하나, 맞는 수업 하나로 요약한 첫 장을 만들고, 나머지는 부록으로 돌린다. 건당 감수 시간이 얼마인지 재서 공유한다(열린 질문).
4. **첫 고객들의 실제 경험을 기록할 것.** 진단 → 리포트 → 수업으로 이어지는 각 단계의 전환율, 리포트를 받은 뒤 "그림 한 장을 끝냈는가"를 측정해, 다음 보드 전에 보고한다.

## 6-1. 사업 설명 (idea.md)

`bulkup/founder/idea.md`

### 아더댄웍스 6축 그림체 진단 (무료 진단 → 유료 리포트 → 수업)

- What it is: 디지털 드로잉 취미러가 21문항(또는 그림 3~5장)으로 자기 그림체를 6축(선·형태·색·질감·구성·정서)과 기본기 8항목으로 진단받고, 어떤 길(그림책·이모티콘·캐릭터 굿즈·인스타툰·포트폴리오/외주)이 맞는지 알려 주는 서비스. 무료 진단은 리드 수집용, 유료 리포트가 첫 매출, 수업이 본 매출.
- Who it is for: 한국의 디지털 드로잉(주로 아이패드·프로크리에이트) 입문~초중급 취미러. 그림을 시작한 지 얼마 안 됐고, 끝까지 마무리하지 못한 그림이 많고, 자기 장점과 디지털 드로잉의 강점을 잘 모르는 사람. 인스타그램으로 유입.
- What it sells, at what price:
  - 무료 진단 (21문항, 연락처 입력 후 결과): 그림체 유형 8종 중 하나, 지금 단계(탐색기~상업 준비), 숨은 강점 2개, 디지털 팁, 1위 길, 7일 루틴.
  - 유료 리포트 29,000원 (런칭가 19,000원): 실제 그림 3~5장을 AI가 분석하고 대표(현직 작가·강사)가 감수. 기본기 8항목 10점 척도, 5개 길 점수·등급, 시장분석, 2주 처방, 4주 연습표, 12주 로드맵, 대표 한마디. 약 14장 분량 문서.
  - 수업: 빈티지 온라인 드로잉 클럽 (매주 수요일 저녁 8시 30분, 프로크리에이트 4주, 가격은 노션 안내), 1:1 맞춤 워크숍 (단기 4회 55만 원 / 중기 12회 프로젝트형), 오프라인 6개 수업.
- Where and how: 온라인. 인스타그램 @other.than.works 캐러셀 → 무료 진단 웹페이지(정적 페이지, 구글 시트로 리드 수집) → 결과 화면·이메일에서 유료 리포트(현재 결제 링크 없음, 인스타 DM 신청) → 수업 신청(구글 폼·노션).
- Budget and constraints: 1인(대표) 운영. 유료 리포트는 대표가 스튜디오 도구로 직접 감수해 발행(1건당 대표 시간 필요). 결제 링크·자동 발송 미구축. 개발은 완료된 MVP(무료 진단 페이지, 대표용 스튜디오, 수집기). 마케팅 예산·현재 팔로워 수·전환 데이터는 아직 없음.

- 무료 결과는 1위 길과 '하고 싶은 길'의 순위만 공개하고, 나머지 순위·점수·등급은 유료로 잠근다. 하고 싶은 길은 동기 가산으로 최소 2위 안에 둔다(그래야 그 길의 수업으로 이어짐).
- 그림 분석 AI는 '관찰'만 하고 점수 해석은 공개된 규칙으로 한다. 캐릭터가 없는 그림은 감점하지 않고 '해당 없음' 처리.

- 아직 없는 숫자: 인스타 팔로워 수, 무료 진단 전환율, 리포트 구매율, 수업 단가별 마진, 고객 획득 비용.

## 10. 부록: 이사회 관점 정의 (lenses.md)

`bulkup/founder/board/lenses.md`

### The three lenses

Summaries of published frameworks, in our own words. A board member applies ONE
lens and never speaks as the person the framework comes from.

#### The Offers lens

Source: Alex Hormozi, *$100M Offers* (2021).

**Pick the market first.** The best offer fails in a bad market. Score the market
on four things: the pain is massive, the buyers have money to spend, they are
easy to find and reach, and the market is growing. A weak market is the most
common reason this lens passes.

**The value equation.** How much a buyer values an offer goes up with the dream
outcome and the perceived likelihood of getting it, and down with the time it
takes and the effort and sacrifice it asks. Score each of the four for this
business. Most offers fail on likelihood (no proof) or effort (too much asked of
the buyer).

**Do not compete on price.** If the only difference is being cheaper, it is a
commodity. Ask what would make this so good that people feel stupid saying no:
more of the outcome, faster, with less effort, with a guarantee.

**Build the stack.** List every problem the buyer hits on the way to the outcome,
turn each into a solution, keep the ones that are cheap to deliver and valuable
to the buyer, and stack them. Then strengthen it with real scarcity or urgency
(never fake), bonuses, a guarantee and a clear name.

Questions this lens asks: Who exactly has this pain and money? Why would they
believe it works? How fast do they get a result? What is the guarantee? Could you
double the price and still be the obvious choice?

#### The Monopoly lens

Source: Peter Thiel with Blake Masters, *Zero to One* (2014).

**Competition destroys profit.** A business in a crowded market fights for thin
margins. The goal is a small market you can dominate, then expand from.

**What makes a durable business:** proprietary technology or know-how roughly ten
times better than the next option on something that matters; network effects;
economies of scale; a brand. Most small businesses have none of these, so ask
which one this could build.

**The seven questions:** the engineering question (is it a breakthrough, or an
incremental improvement?), timing (why now?), monopoly (does it start with a big
share of a small market?), people (is this the right team?), distribution (is
there a way to reach buyers, not just a product?), durability (will it still hold
its position in ten years?), and the secret (what does the founder know that
others do not?).

**Distribution is half of it.** A good product with no way to reach customers is
not a business. Ask how the first 100 customers arrive and what each one costs.

Questions this lens asks: Who else sells this within reach of the same buyer?
What is the small market this can own first? What is the secret? What stops a
copycat in month six?

#### The Product lens

Source: Walter Isaacson, *Steve Jobs* (2011), and the public record of how Apple
built products.

**Focus means saying no.** Most ideas do too many things. Ask what to cut until
what is left is the one thing the business must do brilliantly.

**Start from the experience and work back.** Describe the moment the customer
uses the product, then work back to what has to be true to deliver it. Not the
other way round.

**Own the whole experience.** Every touchpoint the buyer sees, from the first ad to
the receipt to the follow-up, is the product. Seams are where it breaks.

**Taste and craft, including the parts nobody sees.** Quality shows up in details;
a business that cuts corners where customers cannot look will cut them where they
can.

**Simplicity is the hard part.** If the pitch needs a paragraph, the product is not
clear yet. Ask for it in one sentence.

Questions this lens asks: What is the one thing? What does the first five minutes
with this feel like for the customer? What would you cut? Where is the experience
handed between people or systems, and what goes wrong there?

### 그림체 유형 일러스트 넣는 곳

이 폴더에 아래 8개 이름 그대로 PNG를 넣으면 무료 진단 결과 화면, 결과 카드(1080×1350), 대표용 스튜디오 결과지·카드·리포트 표지에 자동으로 들어갑니다.
파일이 없거나 깨져 있으면 기존 폴더 캐릭터가 대신 보이니 일부만 먼저 넣어도 됩니다.

| 파일 이름 | 유형 | 한 줄 |
|---|---|---|
| `clean-deform-story.png` | 표정 부자 캐릭터 작가 | 한 컷만 봐도 무슨 말을 하는지 들리는 그림 |
| `clean-deform-observe.png` | 단정한 마스코트 메이커 | 어디에 붙여도 그 자리에 어울리는 그림 |

| `rough-deform-story.png` | 낙서로 이야기하는 이야기꾼 | 대충 그린 것 같은데 자꾸 보게 되는 그림 |

#### 규격

- 정사각형 투명 PNG, 800×800px 권장 (최소 520px). 화면에서는 84~260px로 줄여 씁니다.
- 캐릭터가 캔버스의 80% 안에 들어오게 여백을 두세요. 무료 결과 카드는 네이비 배경 위, 스튜디오 카드 1은 네이비 띠 위에 올라갑니다.
- 파일 하나당 500KB 이하가 좋아요. 휴대폰에서 결과가 바로 떠야 하니까요.
- 넣은 뒤 `node bulkup/tools/build-public.cjs`를 다시 실행하면 `public/assets/types/`로 복사됩니다.
- claude.ai에 올린 스튜디오에서도 보이게 하려면 게시할 때 `assets/types/*.png`를 함께 올려야 해요.

### OTHER THAN WORKS — 그림 습관 웹앱 MVP

아더댄웍스 수강생이 하루 10분 그림을 시작하도록 돕는 모바일 우선 웹앱입니다. 설치 없이 링크로 열 수 있고, Safari/Chrome의 홈 화면 추가를 지원합니다.

#### 현재 MVP 기능

- 1024×1024 투명 PNG 캐릭터 검사·업로드와 이름 짓기
- Procreate용 캐릭터 템플릿 PNG 다운로드
- 작업 종류 선택과 10분 집중 타이머
- 탭 또는 브라우저 이탈 시 집중 자동 일시정지
- 완료 후 오늘 그림 한 장과 메모 저장
- 월간 기록 캘린더와 최근 작업
- 주간 작업실 소식·상장·선생님 미션
- 누적 집중시간에 따라 열리는 개인 작업실
- 샘플 친구가 있는 공동 작업실과 GALLERY
- 모바일 홈 화면 추가용 웹앱 매니페스트와 오프라인 셸

#### 데이터 범위

캐릭터와 개인 그림 기록은 브라우저의 IndexedDB에 저장됩니다. 따라서 서버나 다른 사람에게 업로드되지 않으며 같은 기기·브라우저에서 다시 열었을 때 유지됩니다. 공동 작업실과 친구 전시는 첫 사용자 테스트를 위한 샘플 데이터입니다.

수강생 간 실제 실시간 상태와 공동 전시를 활성화하는 다음 단계에서는 인증과 이미지 저장소를 갖춘 백엔드 연결이 필요합니다.

#### 개발 실행

```bash
npm install
npm run dev
```

배포용 검증:

```bash
npm run build
npm test
```
