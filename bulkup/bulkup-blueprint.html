왜 이것부터 하나

  1. 재료가 이미 있어요. 6축 방법론과 수강생 사례가 있어서 프롬프트에 넣을 기준이 바로 나옵니다.
  2. 결과물이 곧 광고예요. 결과 카드는 인스타에 공유되는 포맷이라 진단 한 건이 유입 한 건을 만듭니다.
  3. 모든 상품의 입구예요. 진단 결과가 클래스·책·키트 중 무엇을 살지 정해 줍니다.
  4. 데이터가 쌓여요. 진단 100건이면 책 개정, 민간자격 평가 기준, 지원사업 실적 증빙이 됩니다.

03-1 · 프롬프트 설계

AI는 보고, 규칙은 판단하고, 대표는 서명합니다

시스템 프롬프트 핵심 (스튜디오에 실제로 들어간 것)

당신은 17년 차 시각디자이너가 만든 '6축 그림체 진단' 루브릭을 따르는
아트 디렉터 보조입니다. 첨부한 그림 N장은 모두 한 사람이 그린 것입니다.
당신은 관찰만 합니다. 점수 해석, 수업 추천, 가격 안내는 하지 않습니다.

[6축 — 우열이 아니라 위치]
- line (선): 0 = 러프·스케치, 100 = 정돈·클린
- form (형태): 0 = 데포르메·단순화, 100 = 사실·구조
- color (색): 0 = 절제·톤온톤, 100 = 대비·고채도
- texture (질감): 0 = 플랫·디지털, 100 = 아날로그·재료감
- comp (구성): 0 = 정적·중앙, 100 = 동적·여백·대각
- mood (정서): 0 = 담백·관찰, 100 = 서사·감정

[채점 규칙]
1. position: 보이는 것만으로. 애매하면 40~60, 근거에 애매한 이유를 쓴다.
2. consistency(1~5): 그 선택이 여러 장에 걸쳐 의도적으로 유지되는 정도.
   그림이 1장이면 4 이상은 매우 확실할 때만.
3. evidence: 그림 속 구체적 요소(위치·대상·도구)로 한 문장.
4. 말투: ~요/~습니다 섞은 담백한 대화체. 위로 문구·감성 문구 금지.
5. 그림이 아니면 {"error":"not_artwork"}만 답한다.

[출력] summary, axes{6개}, strengths[2], blockers[2], prescriptions[3] JSON 하나

정확도를 올리는 순서

  1. 앵커 세트 18장: 축마다 0·50·100 예시 그림을 대표가 고르고, 각 그림을 한 줄로 설명해 프롬프트에 붙입니다.
  2. 감수 로그: 스튜디오에 저장되는 'AI 점수 vs 대표 수정 점수'를 50건 모읍니다.
  3. 축별 오차 측정: 평균 오차가 15점 넘는 축만 설명을 고칩니다. 목표는 전 축 10점 이하.
  4. 감수 시간 단축: 오차가 줄면 건당 10분 → 3분. 그때 가격을 낮추거나 물량을 늘립니다.

지켜야 할 선

  • 그림 원본은 저장하지 않고 결과만 남깁니다 (스튜디오 기본 동작).
  • '진단'은 평가가 아니라 위치라는 말을 결과지마다 붙입니다.
  • 미성년 기관 수업은 보호자 동의서에 AI 분석 고지를 넣습니다.
  • 6축 축 이름은 지금 가정값이에요. 대표의 실제 6축으로 바꾸는 곳은 스튜디오 코드 맨 위 AXES 한 군데입니다.
