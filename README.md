# OTHER THAN WORKS — 그림 습관 웹앱 MVP

아더댄웍스 수강생이 하루 10분 그림을 시작하도록 돕는 모바일 우선 웹앱입니다. 설치 없이 링크로 열 수 있고, Safari/Chrome의 홈 화면 추가를 지원합니다.

## 현재 MVP 기능

- 1024×1024 투명 PNG 캐릭터 검사·업로드와 이름 짓기
- Procreate용 캐릭터 템플릿 PNG 다운로드
- 작업 종류 선택과 10분 집중 타이머
- 탭 또는 브라우저 이탈 시 집중 자동 일시정지
- 완료 후 오늘 그림 한 장과 메모 저장
- 월간 기록 캘린더와 최근 작업
- 주간 작업실 소식·상장·선생님 미션
- 누적 집중시간에 따라 열리는 개인 작업실
- 샘플 친구가 있는 공동 작업실과 GALLERY
- 모바일 홈 화면 추가용 웹앱 매니페스트와 오프라인 셸

## 데이터 범위

캐릭터와 개인 그림 기록은 브라우저의 IndexedDB에 저장됩니다. 따라서 서버나 다른 사람에게 업로드되지 않으며 같은 기기·브라우저에서 다시 열었을 때 유지됩니다. 공동 작업실과 친구 전시는 첫 사용자 테스트를 위한 샘플 데이터입니다.

수강생 간 실제 실시간 상태와 공동 전시를 활성화하는 다음 단계에서는 인증과 이미지 저장소를 갖춘 백엔드 연결이 필요합니다.

## 개발 실행

