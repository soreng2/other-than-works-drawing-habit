# OTHER THAN WORKS — 그림 습관 웹앱 MVP

아더댄웍스 수강생이 하루 10분 그림을 시작하도록 돕는 모바일 우선 웹앱입니다. 설치 없이 링크로 열 수 있고, Safari/Chrome의 홈 화면 추가를 지원합니다.

## 현재 MVP 기능

- 1024×1024 투명 PNG 캐릭터 검사·업로드와 이름 짓기
- Procreate용 캐릭터 템플릿 PNG 다운로드
- 작업 종류 선택과 5·10·20·30분 타이머, 자유 집중
- 첫 화면의 10분 바로 시작과 작업 종류별 작은 시작 제안
- 탭 또는 브라우저 이탈 시 집중 자동 일시정지
- 완료 후 오늘 그림 한 장과 메모 저장
- 월간 기록 캘린더와 최근 작업
- 주간 작업실 소식·상장·선생님 미션
- 첫 10분부터 누적 집중시간에 따라 조금씩 열리는 개인 작업실
- 현재 작업 중인 친구와 쉬는 친구가 보이는 공동 작업실 지도
- 캐릭터 위 상태 메시지와 수강생 공동 GALLERY
- 호스트가 수정하는 선생님의 한마디와 주간 미션
- 모바일 홈 화면 추가용 웹앱 매니페스트와 오프라인 셸

## 데이터 범위

ChatGPT 로그인을 바탕으로 수강생 명단의 본인 이름을 한 번 연결합니다. 캐릭터·완료 그림은 이미지 저장소에, 프로필·작업 기록·현재 상태·선생님의 한마디는 데이터베이스에 저장되어 다른 기기와 수강생에게 공유됩니다. 브라우저에는 연결이 잠시 끊겼을 때를 위한 최근 개인 상태도 함께 보관합니다.

실명은 본인 확인에만 쓰고, 공동 작업실에는 수강생이 정한 닉네임과 작업친구 이름이 표시됩니다. 순위와 연속 출석 실패 표시는 두지 않습니다.
